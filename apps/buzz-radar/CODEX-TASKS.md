# Buzz Radar: data collection to improve

**Goal:** for any video game name, collect as much content as possible (videos, streams, posts, ads). The user should need to do as little setup as possible, ideally none.

**Areas to improve:**
- TikTok
- Instagram
- X (Twitter)
- Facebook
- YouTube
- Twitch
- Reddit
- Bluesky
- Mastodon
- Hacker News
- Ad libraries: Meta Ad Library, Google Ads Transparency Center, TikTok Ad Library, TikTok Creative Center

Connectors live in `sources.js`. Interfaces are in `CONTRACT.md`. Tests go in `tests/sources.test.mjs`.
